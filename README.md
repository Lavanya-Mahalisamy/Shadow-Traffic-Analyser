# Shadow-Traffic-Analyser
## Overview
Shadow Traffic Analyzer is a web-based network traffic analysis
prototype designed to monitor packet activity, identify potential
risks, and present traffic information through an interactive dashboard.
## Features
- Network traffic monitoring
- Risk score calculation
- Low, Medium and High risk classification
- Traffic statistics visualization
- Alert indication
- Recommended solutions
- Interactive dashboard
## Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js
- LocalStorage
## Project Workflow
User Input
    ↓
Traffic Data Analysis
    ↓
Risk Score Calculation
    ↓
Risk Classification
    ↓
Dashboard Visualization
    ↓
Alert & Suggested Solution
